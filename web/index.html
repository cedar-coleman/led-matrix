Set an admin PIN

The wall needs an admin PIN before anything on it can be changed. Anyone on the gym Wi-Fi can look at this page, but saving athletes, media, the rotation or settings will ask for the PIN.

Write it down somewhere safe. On the real wall the first PIN is set while connected to the wall's own setup Wi-Fi. If the PIN is ever lost, switch the wall off and on again, and as soon as it lights up press and hold the BOOT button on the wall's controller for 10 seconds. That clears the PIN, and you set a new one from the setup Wi-Fi. (Don't hold BOOT while switching on: that puts the controller into programming mode.)
